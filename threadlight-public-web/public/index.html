Windows setup

Set up with an assistant.

Open an assistant that can run commands on your Windows PC, such as a local Codex or Claude Code session. Give it the prompt below and tell it which provider you use. It can check the requirements, install the selected plugin and launch Threadlight. You handle sign-in, hook trust and Windows approval prompts.

Give your assistant this prompt

Help me set up Threadlight on this Windows PC. Read https://threadlight.jocosewasp4.chatgpt.site/#setup and the setup guide in https://github.com/JusamaGB/Threadlight. Ask whether I use Codex, Claude Code or both. Check the tools for my choice and explain any changes. With my approval, install Threadlight from a folder I can keep using the matching --providers option. Pause for my sign-in, hook trust and Windows prompts. Run the same provider-specific check after setup and help me verify a new local chat in the overlay.

Manual setup on Windows · Git Bash or PowerShell

  1. Check the requirements for your provider

    Use Windows x64 (Windows 10 version 1803 or later, or Windows 11), Node.js 22.16 or later and Windows curl.exe. For Codex, use a compatible native codex.exe from Codex Desktop or on your PATH. For Claude Code, install Claude Desktop and the Claude Code CLI. Use Git to clone the source, or download the source ZIP.

  2. Choose your Windows terminal

    In VS Code, open the terminal profile menu and choose Git Bash or PowerShell. If your terminal is already in a folder where you want to keep Threadlight, continue to the next step. Otherwise, use your shell’s example to create one.

    Git Bash on Windows
    mkdir -p "$HOME/Threadlight Projects"
cd "$HOME/Threadlight Projects"
    PowerShell on Windows
    New-Item -ItemType Directory -Force -Path "$HOME/Threadlight Projects" | Out-Null
Set-Location -LiteralPath "$HOME/Threadlight Projects"

  3. Get the source and check your setup

    These commands work in either Windows terminal. The example selects Codex alone. For Claude Code alone, use claude in place of codex. For both providers, use claude,codex. Keep that choice for every install and check command.

    git clone https://github.com/JusamaGB/Threadlight.git
cd Threadlight
node scripts/install.mjs --check --providers codex

    If you downloaded the ZIP, extract it in File Explorer and open your chosen terminal in the folder containing package.json. Start with the provider-specific check command. On a fresh installation, missing app packages, build output and plugin registration are expected.

  4. Install and check Threadlight

    Once the prerequisites pass, install from the source folder. The installer builds and launches the overlay and registers the selected plugin. Then check that same provider:

    node scripts/install.mjs --providers codex
node scripts/install.mjs --check --providers codex

  5. Verify your first thread

    For Codex, sign in, review and trust the Threadlight hooks in /hooks, then open a new local Codex chat. For Claude Code, check claude auth status, finish sign-in if needed and start a new Claude Code session. Open the corner dot and look for your thread. Full setup guide

Help & compatibility

Common questions.

Can I use Codex without Claude?

Yes. From the source folder, run node scripts/install.mjs --providers codex. It registers the Codex plugin and selects Codex. Run node scripts/install.mjs --check --providers codex to check the installation. Complete your own Codex sign-in, review hook trust in /hooks and start a new local Codex chat to verify activity. Windows 10 installation results · Codex plugin guide

Can Threadlight follow chats in my browser?

A browser tab alone cannot connect its chats to the overlay. The public build follows local Claude Code and Codex coding sessions. The development build can also read and reply to ordinary ChatGPT chats through signed-in Codex Desktop, and Perplexity chats through the signed-in Perplexity desktop app. These account-chat features have not shipped in the public source preview.

Is there a Windows installer or a Mac version?

The public alpha is a Windows source build. There is no packaged release to download. Keep the source folder after setup because the app runs from it. Desktop integrations can change when provider apps update.

What stays on my PC?

Threadlight reads local session records and workspace files for the features you use. It has no Threadlight account or analytics service. Sending a reply invokes your provider under your own account. Local dictation uses a downloaded speech model. GPT Live sends microphone audio to the provider while active. Local data details · Voice and network use

Who can read a Shared Space?

Connecting a chat requires approval in Threadlight. Match its verification code, check the requested space and permissions, then approve the intended connection. Project direct messages also require project DMs to be enabled. Shared memory guide

Why is my thread missing?

Check the tray for Threadlight and run the diagnostic with the providers you installed, for example node scripts/install.mjs --check --providers codex. For Codex, check sign-in and hook trust, then open a new local chat. For Claude, open Claude Desktop, check claude auth status and start a fresh Claude Code session after installing the plugin.

How do I remove Threadlight?

From the source folder, run node scripts/install.mjs --uninstall. The installer uses its record to remove the plugin registrations it added. It keeps your settings and project data by default. Uninstall instructions
