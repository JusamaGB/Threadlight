Windows setup

Set up with an assistant.

Open an assistant that can run commands on your Windows PC, such as a local Codex or Claude Code session. Give it the prompt below and tell it which provider you use. It can check the requirements, set up your chosen connections and launch Threadlight. You handle sign-in, hook trust and Windows approval prompts.

Give your assistant this prompt

Help me set up Threadlight on this Windows PC. Read https://threadlight.jocosewasp4.chatgpt.site/#setup and the setup guide in https://github.com/JusamaGB/Threadlight. Ask which connections I use: Codex (including ChatGPT through Codex Desktop), Claude Code or Perplexity Desktop. Check the tools for my choice and explain any changes. With my approval, install Threadlight from a folder I can keep using the matching --providers option. Pause for my sign-in, hook trust and Windows prompts. Run the same provider-specific check after setup and help me verify a new local chat in the overlay.

Choose Codex, Claude Code, Perplexity or any combination. Codex-only setup works without Claude.

Manual setup on Windows · Git Bash or PowerShell

  1. Check the requirements for your provider

    Use Windows x64 (Windows 10 version 1803 or later, or Windows 11) and Node.js 22.16 or later. Codex and Claude Code also require Windows curl.exe. For Codex, use a compatible native codex.exe from Codex Desktop or on your PATH. For Claude Code, install Claude Desktop and the Claude Code CLI. For Perplexity, use the signed-in Perplexity Windows app. Use Git to clone the source, or download the source ZIP.

  2. Choose your Windows terminal

    In VS Code, open the terminal profile menu and choose Git Bash or PowerShell. If your terminal is already in a folder where you want to keep Threadlight, continue to the next step. Otherwise, use your shell’s example to create one.

    Git Bash on Windows
    mkdir -p "$HOME/Threadlight Projects"
cd "$HOME/Threadlight Projects"
    PowerShell on Windows
    New-Item -ItemType Directory -Force -Path "$HOME/Threadlight Projects" | Out-Null
Set-Location -LiteralPath "$HOME/Threadlight Projects"

  3. Get the source and check your setup

    These commands work in either Windows terminal. The example selects Codex alone. For Claude Code or Perplexity alone, replace codex with claude or perplexity. For multiple connections, use a comma-separated list such as claude,codex. Keep that choice for every install and check command.

    git clone https://github.com/JusamaGB/Threadlight.git
cd Threadlight
node scripts/install.mjs --check --providers codex

    If you downloaded the ZIP, extract it in File Explorer and open your chosen terminal in the folder containing package.json. Start with the provider-specific check command. On a fresh installation, missing app packages, build output and plugin registration are expected.

  4. Install and check Threadlight

    Once the prerequisites pass, install from the source folder. The installer builds and launches the overlay and registers plugins for selected coding providers. Perplexity connects through its Windows app. Then check the same provider selection:

    node scripts/install.mjs --providers codex
node scripts/install.mjs --check --providers codex

  5. Verify your first thread

    For Codex, sign in, review and trust the Threadlight hooks in /hooks, then open a new local Codex chat. For Claude Code, check claude auth status, finish sign-in if needed and start a new Claude Code session. For Perplexity, choose Chat or All in Threadlight and open a known conversation. Use the dot or tray to open the panel. Full setup guide

Help & compatibility

Common questions.

How does the shared browser work?

Open Browser from the panel header in Threadlight 0.1.0-alpha.2. Give a connected Claude or Codex chat access to the page and it can click and type alongside you. You can take back control or revoke access. Get the source release and optional VS Code extensions.

Does Threadlight support Kimi?

Kimi integration is in development. It’s hidden in the public preview.

Can I use Codex without Claude?

Yes. From the source folder, run node scripts/install.mjs --providers codex. It registers the Codex plugin and selects Codex. Run node scripts/install.mjs --check --providers codex to check the installation. Complete your own Codex sign-in, review hook trust in /hooks and start a new local Codex chat to verify activity. Windows 10 installation results · Codex plugin guide

Can Threadlight follow chats in my browser?

A browser tab alone cannot connect its chats to the overlay. The public build follows local Claude Code and Codex coding sessions. You can also read and reply to ordinary ChatGPT chats through a compatible, signed-in Codex Desktop app with a known local Codex chat, and to Perplexity chats through the signed-in Perplexity Windows app. Choose Chat or All in Threadlight to see them. Account chat guide

Is there a Windows installer or a Mac version?

The desktop app runs from source on Windows. The 0.1.0-alpha.2 release includes the source and separate VSIX downloads for Live Coach and Margin Notes. Keep the source folder after setup because the app runs from it.

What stays on my PC?

Threadlight reads local session records and workspace files for the features you use. It has no Threadlight account or analytics service. Sending a reply invokes your provider under your own account. Local dictation uses a downloaded speech model. GPT Live sends microphone audio to the provider while active. Local data details · Voice and network use

Who can read a Shared Space?

Connecting a chat requires approval in Threadlight. Match its verification code, check the requested space and permissions, then approve the intended connection. Project direct messages also require project DMs to be enabled. Shared memory guide

Why is my thread missing?

Check the tray for Threadlight and run the diagnostic with the providers you installed, for example node scripts/install.mjs --check --providers codex. For Codex, check sign-in and hook trust, then open a new local chat. For Claude, open Claude Desktop, check claude auth status and start a fresh Claude Code session after installing the plugin. For account chats, check that the signed-in desktop app is open and Chat or All is selected.

How do I remove Threadlight?

From the source folder, run node scripts/install.mjs --uninstall. The installer uses its record to remove the plugin registrations it added. It keeps your settings and project data by default. Uninstall instructions
