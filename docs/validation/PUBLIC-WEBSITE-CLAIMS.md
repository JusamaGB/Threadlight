# Public website claim review

8 November 2026. The downloadable source was checked against public Git commit `2783bd077f824ee3d8f18a9f3ac376a28acc2c48`. This audit covers the [public Site](https://threadlight.jocosewasp4.chatgpt.site/) and its Haail copy. Website checks used a signed-out browser. Installation behavior was checked against published code and guides without installing on the active PC.

| Manual Windows setup                                 | The public installer checks Windows 10 build 17134 (1803) or later, Node.js 22.16 or later, Windows curl, Claude Desktop and the Claude Code CLI. Git is needed to clone. The ZIP route uses the extracted source folder. The manual guide gives distinct folder commands for Windows Git Bash and PowerShell, then shared Git and Node commands. Each shell cloned public main in its own disposable path containing spaces and ran the published read-only installer check. The probes left dependencies uninstalled. A fresh preflight may report uninstalled app components. Test the hooks using a new Claude Code session after installation. The local checkout’s provider-selection flag is absent from public main. | FAQ · privacy                                        | Session records and workspace files are read locally. Threadlight has no product account or analytics service. The older public privacy document describes local dictation only, so the Site also points to the README’s explicit Live distinction.
