# Roadmap

Priorities, not delivery dates or promises:

1. Make first-run setup and version compatibility easier to diagnose.
2. Bring Claude Code back toward parity and repeat live acceptance checks.
3. Improve ordinary ChatGPT and Perplexity chat stability, history and rich content.
4. Validate Perplexity Computer actions before expanding its interactive controls.
5. Continue Kimi runtime integration behind the disabled public feature gate.
6. Improve accessible compact UI, provider layouts and distribution.

Kimi remains hidden until there is a usable, verified execution path. Scheduled-task
cards and provider widgets need verified state and action support before they become
clickable controls. Triple/Quad layouts are mapped but not implemented.
