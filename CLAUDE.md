# Shared repository instructions

Read and follow [AGENTS.md](AGENTS.md) before working in this repository. Its
working-copy, validation and documentation rules apply to Claude chats too.

In particular, update `CHANGELOG.md` under **Unreleased** during the same work
session as notable user-visible changes, update affected README/setup guidance,
and preserve validation limits before reporting completion. Coordinate edits to
shared documentation with other active chats.
